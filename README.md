# 한 수 · 장기 알까기

마우스와 모바일 터치로 즐기는 1인용 장기 알까기. AI의 빨간 말을 먼저 모두 판 밖으로 밀어내면 승리합니다. 동시에 양쪽 말이 모두 사라지면 무승부입니다.

## 플레이

파란 말을 누른 채 **발사 방향의 반대쪽으로** 당긴 다음 놓습니다. 길게 당길수록 강하게 발사합니다. 모든 말이 멈춘 뒤 AI와 차례를 교대합니다. 난이도 3단계와 선택형 효과음을 지원합니다.

## 실행

Node.js 설치 후 이 폴더에서 `npm run dev`를 실행하고 http://localhost:3000 에 접속합니다. 설치할 외부 패키지가 없습니다. 또는 정적 파일 서버로 이 폴더를 서비스할 수 있습니다.

## GitHub → Vercel

1. GitHub에 새 저장소를 만들고 **이 폴더 안의 파일들**을 저장소 루트에 업로드합니다. tests 폴더도 함께 올립니다.
2. Vercel에서 Add New → Project → 해당 GitHub 저장소를 Import 합니다.
3. Root Directory는 `package.json`, `vercel.json`, `index.html`이 들어 있는 폴더로 설정합니다. 폴더 자체를 업로드했다면 `Janggi-Flick`을 선택합니다.
4. Framework Preset은 **Other**로 선택합니다. 함께 제공된 `vercel.json`이 Build Command를 `npm run build`, Output Directory를 `dist`로 지정합니다. 대시보드에서 직접 설정할 때도 같은 값을 사용합니다.
5. Deploy 합니다. 기존 프로젝트는 변경 파일을 GitHub에 올리고 새 커밋으로 재배포합니다.

로컬에서도 `npm run build`로 배포용 정적 파일 5개를 `dist/`에 생성할 수 있습니다. `dist`는 생성물이므로 GitHub에 올리지 않아도 됩니다.

별도의 API 키, 백엔드, 환경 변수는 필요하지 않습니다. 한글 웹폰트는 Google Fonts를 사용하며, 네트워크가 없으면 기기의 기본 글꼴로 표시됩니다.

## 물리 규칙

| 말 | 질량 |
|---|---:|
| 졸·병 | 1.00 |
| 마 | 2.00 |
| 상 | 2.70 |
| 사 | 3.50 |
| 포 | 4.40 |
| 차 | 5.50 |
| 궁 | 7.00 |

같은 드래그 길이에서는 발사 속도가 같고, 운동량은 질량에 비례합니다. 무거운 말은 상대에게 더 큰 충격을 전달하며 충돌로 잘 밀리지 않습니다. 양 팀의 같은 종류에는 완전히 동일한 값이 적용됩니다. 궁은 졸·병의 7배 질량이며 지름은 약 2.2배입니다. 충돌 반발계수는 0.94이며, 가벼운 말이 무거운 말을 정면으로 치면 강하게 되튕깁니다. 마찰 감속은 `380 × 질량^0.12 + 속도 × 0.45`로 적용되어 저속에서도 확실히 멈춥니다. 물리 시간 간격은 1/240초입니다. 말이 판 경계 밖으로 완전히 나가면 제거됩니다. AI는 여러 발사 방향과 세기를 실제 게임과 같은 마찰·충돌 물리로 시뮬레이션합니다. 상대 말 탈락, 아군 손실, 반동과 가장자리 위험, 다음 공격을 위한 접근을 평가하고 최종 후보를 게임과 같은 1/240초 간격으로 재검증합니다. 난이도는 탐색 후보 수와 조준 각도 범위를 조절하며 무작위 오조준을 적용하지 않습니다. 새 게임을 시작하면 이전 AI 계산을 취소합니다.

`npm test`로 충돌 물리 검증을 실행할 수 있습니다. 디자인과 장기판은 HTML Canvas로 직접 그려 이미지 파일에 의존하지 않습니다.
